# Gold-Set Structure (Eval Foundation)

How ground-truth evaluation data is organized from day one, so the eval harness (CP26) has a stable foundation and every AI checkpoint (CP12+) can measure itself immediately.

## Principles

1. **Versioned & immutable.** A gold set release (`goldset-v1`, `goldset-v2`, …) never changes after release; new labels create a new version. Eval results are meaningless without a pinned dataset version.
2. **Sliced by difficulty and type.** Aggregate accuracy hides failures. Every document carries slice tags so we always know accuracy *per slice*.
3. **Labels follow the grounding contract.** Ground truth is an `ExtractionResult` (same schema as predictions) — evaluation is a like-for-like comparison, including bboxes.
4. **Synthetic first, real later.** v1 gold sets are synthetic (pixel-accurate by construction). De-identified real documents (CP27) are added as separate slices — never mixed silently, so we can report synthetic vs. real accuracy honestly.

## Directory layout

```
evals/goldsets/
  goldset-v1/
    manifest.json           # version, seed(s), counts, slice distribution, provenance
    docs/
      pa_000001.png
      pa_000001.labels.json # ExtractionResult ground truth
      ...
```

## Slice tags (in the manifest, per document)

| Dimension | Values |
|-----------|--------|
| `doc_type` | the taxonomy types |
| `degradation` | `clean` · `fax` · `bad_fax` |
| `source` | `synthetic` · `real_deid` (from CP27) |
| `features` | `tables`, `handwriting` (later), `multilingual` (later), `checkboxes` (later) |

## Metrics computed per slice (CP26)

- Field accuracy (exact + normalized), **critical-field accuracy** (the 95% NFR).
- Hallucinated-field rate (predicted fields absent from ground truth) — target ≤ 0.5%.
- Missed-field rate (required fields present in truth, absent in prediction).
- Grounding IoU (predicted bbox vs. truth bbox overlap) — verifies *where*, not just *what*.
- Table cell accuracy + structure correctness.
- Classification accuracy + confusion matrix; confidence calibration (ECE) per field kind.

## Bootstrap plan

`goldset-v1` = 300 synthetic PA documents from `chartwright-synthdata` (seed-pinned: 40% clean / 40% fax / 20% bad_fax). It ships when CP12 needs its first accuracy numbers, generated by a one-command script so anyone can reproduce it bit-for-bit from the manifest.
